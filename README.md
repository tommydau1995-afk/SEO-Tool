# SEO AI Studio V2 — Windows

Dự án này tự động tạo:

```text
SEO_AI_Studio_V2_Setup.exe
```

Sau khi cài, máy người dùng không cần Python, pip hoặc CMD.

## Tạo Setup.exe bằng GitHub

1. Tạo repository GitHub mới, ví dụ `seo-ai-studio-v2`.
2. Giải nén ZIP này.
3. Upload **toàn bộ nội dung bên trong thư mục** lên repository.
4. Mở tab **Actions**.
5. Chọn **Build SEO AI Studio V2 Setup**.
6. Nhấn **Run workflow**.
7. Khi có dấu tích xanh, mở workflow.
8. Tải artifact **SEO-AI-Studio-V2-Setup**.
9. Giải nén artifact để nhận `SEO_AI_Studio_V2_Setup.exe`.
